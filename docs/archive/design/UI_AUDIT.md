**图片概述：**这是一个浅色、绿色品牌调性的 AI 模型导航首页，包含首屏选型入口、数据统计、三种探索路径、任务与预算筛选，以及模型卡片列表。

## 1. UI 问题

### 首屏视觉

- 右侧“30s 轨道图”视觉占比很大，但不能直接操作，装饰性强于功能性。
- Hero 同时出现两个按钮、搜索框、分类标签和轨道信息卡，焦点分散。
- 大面积浅绿背景、浅灰文字和细边框导致整体对比度偏低。
- 主标题字号和字重过强，与后续区块的视觉落差太大。
- 首屏高度偏高，模型内容需要滚动较远才出现。


### 组件表现

- 卡片、Chip、按钮大量使用相似圆角边框，组件层级不够明确。
- 多种图标风格混用，部分符号语义不直观。
- 模型卡信息较完整，但缺少最关键的操作：**查看、对比、试用**。
- “热度 29”“A/B”等字段没有解释，理解成本较高。
- 价格格式不统一，输入价、输出价的含义需要明确标注。


### 布局与密度

- 页面纵向留白过多，信息密度不像 OpenRouter，工具效率感不足。
- 区块标题右侧说明距离主体过远，视线来回移动。
- “场景推荐”和“预算选择”占用大量空间，却只提供简单跳转。
- 四列模型卡在窄屏下需要特别处理，否则信息会过度压缩。

## 2. 信息层级问题

当前首页同时承担了：

1. 品牌介绍
2. 模型搜索
3. 任务推荐
4. 能力筛选
5. 预算筛选
6. 热门榜单
7. 数据规模展示


功能都合理，但没有明确主线。

### 建议的核心路径

**一级目标：找到模型**

将首屏统一为一个强入口：

> 搜索模型，或描述你要完成的任务



支持自然语言输入，例如：

> “需要支持中文、长上下文、低于 ¥5/百万 Token 的代码模型”



### 推荐层级

1. **搜索 / 描述任务**
2. **快速筛选：能力、价格、上下文、厂商**
3. **推荐结果 / 热门模型**
4. **进入详情或加入对比**
5. 厂商地图、知识库等探索型内容


### 建议弱化

- “32 厂商 / 44 系列 / 118 型号”属于信任信息，不应独占一整行。
- “三条路径”与顶部导航重复。
- 场景和预算应该成为筛选器，而不是两个独立大区块。
- 版本标识移入产品菜单或更新日志。

## 3. Design Token

建议结合：

- **OpenRouter：**高信息密度、模型数据表达
- **Linear：**精确间距、克制层级、快捷操作
- **Vercel：**黑白基础、强排版、清晰边界


### 色彩

控制在 5 色以内：

```css
--background: #fafafa;
--surface: #ffffff;
--foreground: #171717;
--muted: #737373;
--brand: #4f7c3a;
```

绿色只用于品牌、选中状态和关键 CTA。紫色、橙色不再承担结构性装饰，仅用于模型模态分类且降低饱和度。

### 边框与层级

```css
--border-subtle: color-mix(in srgb, var(--foreground) 10%, transparent);
--border-strong: color-mix(in srgb, var(--foreground) 18%, transparent);

--radius-sm: 6px;
--radius-md: 10px;
--radius-lg: 14px;
```

减少胶囊形组件；只有标签、状态和过滤条件使用全圆角。

### 字体层级

```plaintext
Display   56/60  650
H1        40/48  650
H2        28/36  600
H3        18/28  600
Body      15/24  400
Meta      13/20  450
Mono      13/20  价格、Token、延迟
```

建议正文使用 Geist Sans，模型参数和价格使用 Geist Mono。

### 间距

采用稳定的 4px 系统：

```plaintext
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96
```

页面最大宽度建议 `1280px`，区块间距由目前约 `120–160px` 收缩到 `64–96px`。

## 4. 重构方案

### 第一屏：产品工作台化

```plaintext
导航
标题：为你的任务找到正确的 AI 模型
统一搜索 / Prompt 输入框
快捷条件：任务、预算、上下文、模态
[开始匹配] [浏览全部模型]

热门搜索：代码生成 / 长上下文 / 免费 / 图像生成
```

删除当前轨道图，替换为一个真实的推荐结果预览，体现“输入任务 → 获得模型”的价值。

### 第二屏：模型浏览器

将热门模型直接提升到首屏下方：

- 顶部：筛选器、排序、搜索结果数量
- 主体：紧凑表格或列表
- 字段：模型、厂商、输入/输出价格、上下文、能力、速度
- 固定操作：详情、加入对比
- 支持表格与卡片视图切换


这部分应更接近 OpenRouter，而不是营销卡片墙。

### 第三屏：任务模板

把现有场景 Chip 改成紧凑模板：

- 编程
- 推理
- 内容创作
- 文档分析
- 图像理解
- Agent


选择后直接预设筛选条件，并说明筛选依据。

### 第四屏：信任与数据

在页面底部集中展示：

- 数据更新时间
- 价格来源
- 模型覆盖数量
- 推荐评分方法
- 数据纠错入口


### 优先级

**P0**

- 合并搜索、任务和预算入口
- 模型列表提前
- 增加对比与详情操作
- 统一价格和评分语义


**P1**

- 建立完整 Token 系统
- 压缩留白与圆角
- 重构筛选器和模型卡
- 完善移动端布局


**P2**

- 快捷键搜索
- 自然语言选型
- 最近查看、保存筛选
- 数据更新时间与推荐解释


整体方向应从当前的“绿色营销型知识门户”，转为**克制、紧凑、可搜索、可比较的模型决策工具**。
